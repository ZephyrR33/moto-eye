# ADR-0002 — Разделить UART и USB ADB

**Статус:** принято · **Дата:** 2026-11-04

## Контекст

После отдельных перезапусков и нестабильного USB доступ к журналам загрузки нельзя обеспечить только средствами ADB. Однако повседневная работа через UART неудобна для управления Android-приложениями.

## Решение

Сохранить два независимых диагностических канала: UART0 115200 для BOOT0/U-Boot/kernel и аварий, USB ADB для команд Android и графических тестов. Не использовать питание USB–UART как источник питания модуля.

## Последствия

Повышается наблюдаемость загрузки, уменьшается время локализации отказов, но стенд требует дополнительного адаптера и аккуратной электрической коммутации. Для финального устройства UART следует ограничить по соображениям безопасности.
