## Условные обозначения

- **Подтверждено:** сведения, считанные непосредственно с платы, ответ ADB или исходный скриншот.
- **По истории:** описание ранее выполненного шага без полной повторной верификации.
- **Гипотеза:** объяснение, для которого пока недостаточно измерений.
- **Планируется:** функциональность, не реализованная в текущем образце.

## Принцип обновления

Добавляя новые характеристики, фиксируйте измерительное средство, условия подключения, прошивку и дату. Документируя изменения VBUS, не предполагайте автоматически совместимость другого модуля A133. Публичные файлы не должны содержать необработанных журналов или чужого ПО.
