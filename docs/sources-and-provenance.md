# Источники, происхождение данных и уровень достоверности

## 1. Внутренние свидетельства

**S-01 — Архивная история разработки.** Текстовый экспорт переписки, содержащий многочисленные промежуточные действия с Baidu, CH341A, USB/FEL, PhoenixSuit и исходными документами изготовителя. Переписка полезна для восстановления хронологии, но некоторые ранние утверждения не прошли независимую проверку и могли корректироваться далее.

**S-02 — UART-журнал `a133_diagnostic.txt`.** Полная исходная локальная запись (непосредственно в публичный репозиторий не включена без редактирования). Содержит BOOT0, U-Boot, Linux и Android вплоть до таймстампов ядра >50 с; в ней виден успешный ответ диагностического запроса с маркерами `===DIAG===`/`===END===`.

**S-03 — Дополнительные журналы UART.** Отдельные пользовательские копии наблюдений при подключённом и отключённом USB0, включая повторный BOOT0 примерно после 23,7 с и более поздние сообщения на >120 с. Часть текста содержит искажения последовательного потока/копирования.

**S-04 — Вывод Android ADB.** Проверенный в финальной беседе набор команд и ответов: `adb devices -l`, `getprop`, `cat /proc/uptime`, `id`, `wm size`, `wm density`, `dumpsys SurfaceFlinger`, `pm list packages -3`.

**S-05 — PNG-контрольный кадр.** Файл `assets/android-desktop-1280x720.png`, полученный через ADB. Подтверждает наличие программного кадра Android 1280 × 720 и отображаемого системного рабочего стола, но не физического дисплея.

**S-06 — Фотография платы.** Файл `assets/a133-core2-prototype.jpg`; показывает модуль A133_CORE2 на стенде. Используется как иллюстрация объекта, не как электрическая документация.

## 2. Документация изготовителя

Материалы, найденные в установленном на ПК заводском пакете `REVB-A133资料`:

| Название файла | Назначение | Доступность в этом репозитории |
| --- | --- | --- |
| `REVB-A133-V2使用手册.pdf` | Руководство REVB-A133-V2 | Указано происхождение, исходник не включён |
| `A133-Core2核心板硬件手册.pdf` | Аппаратное руководство Core2 | Указано происхождение, исходник не включён |
| `A133-Core2核心板引脚说明.pdf` | Распиновка Core2 | Указано происхождение, исходник не включён |
| `REVB-A133V2-HDMI720P-AW869A-202302.zip` | Архив Android 10 | Не включён (проприетарное ПО) |
| `REVB-A133V2-HDMI720P-AW869A-202302.img` | Образ для PhoenixSuit | Не включён |
| `PhoenixSuit V1.0.7` | Утилита прошивки | Не включена |

В промежуточных материалах встречалась также схема `RER-A133-Core-原理图.pdf` для другой вариации A133-Core. **Она не является подтверждением разводки A133_CORE2 V2** и сознательно не используется как окончательная электрическая схема.

## 3. Официальные внешние справочные ресурсы

- [Android Debug Bridge — Android Developers](https://developer.android.com/tools/adb) — принципы доступа к устройству, команды adb.
- [scrcpy — официальный GitHub Genymobile](https://github.com/Genymobile/scrcpy) — возможный инструмент управления Android с ПК, на данном устройстве ещё не испытан.
- [Android Open Source Project](https://source.android.com/) — материалы по программной архитектуре Android.

Эти ссылки приведены для дальнейшего изучения; аппаратно-специфические выводы сделаны из локальных журналов и документов, а не из общих интернет-страниц.

## 4. Система обозначений уверенности

| Уровень | Критерий | Пример |
| --- | --- | --- |
| A — проверено устройством | Непосредственный вывод команды/лога | Android 10, `uid=0`, 1280×720 |
| B — исторически документировано | Указано в архиве работ; нет независимого исходного объекта в репо | Имя выбранной прошивки, часть распиновки |
| C — инженерная гипотеза | Осмысленное объяснение без прямой проверки | Роль VBUS/PMU в ранних сбросах |
| D — план | Предусмотрено архитектурой | Дисплей шлема, GNSS, HUD-приложение |

## 5. Проверка перед публичной публикацией

1. Не коммитить исходные полные логи без редактирования идентификаторов.
2. Не публиковать файлы с ключами, токенами Baidu, приватными ссылками и персональными путями.
3. Не распространять сторонние образы и установщики без проверки лицензий.
4. Не использовать неподтверждённую карту VBUS как инженерную инструкцию по подключению.
5. Все новые числовые характеристики снабжать измерением или выводом программы, временем и условиями.
