# Проверяемые свидетельства

В `samples/` находятся **обезличенные выдержки** из зафиксированных сеансов. Прежде чем публиковать новые данные из команд `adb`, UART, `dmesg` и `logcat`, убедитесь, что серийные номера, MAC, адреса сети, токены и частные пути удалены.

- [`uart-diagnostic.redacted.log`](samples/uart-diagnostic.redacted.log) — очищенная копия UART-журнала загрузки и исполнения команды.
- [`adb-verification.txt`](samples/adb-verification.txt) — ответы ADB, подтверждающие Android 10, root и Display 0.
- [Скриншот 1280 × 720](../assets/android-desktop-1280x720.png) — графический результат, полученный через ADB.

Полный журнал одного сеанса на 667 секунд и аппаратные измерения пока отсутствуют. Сведения о времени работы приведены по непосредственному выводу `cat /proc/uptime`.
