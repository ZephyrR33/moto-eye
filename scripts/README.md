# Командные инструменты стенда MOTO EYE

Приведённые сценарии написаны для **Windows PowerShell 5.1+** и используют стандартный `System.IO.Ports` или Android SDK Platform-Tools. Все штатные операции предназначены для **чтения/диагностики**, без перепрошивки, изменения Android-свойств, отключения системных сервисов или установки стороннего ПО.

| Скрипт | Задача | Внешнее подключение |
| --- | --- | --- |
| `Get-A133Status.ps1` | Подключённый ADB, Android/USB/root/экран | USB0 ADB |
| `Save-A133Screenshot.ps1` | PNG рабочего стола без проблем бинарного `>` | USB0 ADB |
| `Export-A133Diagnostics.ps1` | Локальные dmesg, logcat, getprop, dumpsys | USB0 ADB |
| `Watch-A133Uart.ps1` | Отслеживание BOOT0 и Android-загрузки | USB–UART 3.3 В |

## Быстрый старт

В PowerShell откройте корневую папку репозитория:

```powershell
.\scripts\Get-A133Status.ps1
.\scripts\Save-A133Screenshot.ps1 -OutputPath '.\a133-screen.png'
.\scripts\Watch-A133Uart.ps1 -Port COM6 -DurationSeconds 120 -LogPath '.\logs\uart-01.txt'
.\scripts\Export-A133Diagnostics.ps1
```

Для поиска ADB скрипты проверяют системный `PATH`, затем `%USERPROFILE%\AndroidTools\platform-tools\adb.exe`. Если в системе несколько Android-устройств, укажите `-Serial` и серийный номер через локальную команду `adb devices -l`; никогда не записывайте чужой серийный номер в общие примеры.

## PowerShell execution policy

Если локальная политика запрещает запуск `.ps1`, изучите текущую политику `Get-ExecutionPolicy -List` и правила вашей системы. Не требуется отключать защиту Windows или бесконтрольно задавать `Unrestricted`. При допустимой корпоративной/домашней политике можно воспользоваться ограниченным текущим процессом:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
```

## Результаты и безопасность

- Папка `logs/` игнорируется Git; данные из неё не надо публиковать без редактирования.
- `Export-A133Diagnostics.ps1` может сохранять серийные номера, сведения об установленных приложениях и сети.
- `Watch-A133Uart.ps1` подсчитывает сообщения BOOT0. Если мониторинг запущен **после** старта устройства, первый BOOT0 может означать уже очередную перезагрузку, поэтому выводить абсолютный номер перезагрузки только из счётчика нельзя.
- `Save-A133Screenshot.ps1` по умолчанию сохраняет PNG в локальный каталог `captures/`, исключённый из Git, а на устройстве записывает файл во временный путь `/sdcard/moto-eye-capture.png` на Android. Это не трогает системные разделы.
- Действия с проводкой, VBUS и загрузочными контактами не автоматизированы и описаны в [разделе электропитания](../docs/power-and-usb.md).

Скрипты подготовлены по результатам реальных команд, но не исполнялись непосредственно против устройства в среде сборки этого репозитория. Перед промышленным использованием рекомендуется интеграционный прогон на текущем стенде.
