# Архивный PowerShell-инструмент получения пакета REVB-A133

В каталоге сохранён **исторический** скрипт `Download_A133.ps1` из подготовленного ранее пакета `MotoEye_A133_AutoDownload.zip`. Он описывает этап получения заводских материалов из Baidu Netdisk в конце октября — начале ноября 2026 года.

## Назначение

Скрипт работает с установленным пользователем BaiduPCS-Go v4.0.2, использует существующий сеанс авторизации, рекурсивно перечисляет каталог `/REVB-A133资料`, сверяет приблизительный размер уже скачанных файлов и запускает последовательную докачку. Он не содержит паролей, cookie или иных данных доступа.

## Важные ограничения

- **Не является частью Android-прошивки или управляющего ПО MOTO EYE.**
- Не проверен повторным запуском в текущей среде подготовки репозитория.
- Содержит ранее использованные абсолютные пути к диску `E:\` и каталогу `BaiduNetdiskDownload`; перед запуском на другой машине их потребуется осознанно изменить.
- Интерфейс BaiduPCS-Go и формат выдачи каталога могут поменяться. Скорость и доступность скачивания не гарантируются.
- Скачивает сторонние материалы, которые не включены в Git и могут иметь отдельные условия распространения.
- Может создавать и перезаписывать локальные файлы в назначенной папке. Изучите код перед использованием.

Исходный `.cmd`-запускатель намеренно не перенесён: он запускал Windows PowerShell с параметром `ExecutionPolicy Bypass`; для публикации безопаснее оставить прямой, осознанный запуск `.ps1` в соответствующей политике безопасности.
